Apple 실리콘 Mac 전용

일회용이면서 재현 가능한 환경 — 장난감 같은 VM 앱이 아닙니다.

Velo Workspaces는 AI 연구자, QA 엔지니어, DevOps 전문가, 소프트웨어 엔지니어가 실제로 일하는 방식을 중심으로 만들어진, 진짜 격리된 Linux 및 macOS 환경을 Mac에서 실행합니다 — 흔한 “다른 OS 실행해보기” 같은 재미거리가 아닙니다.

대상 사용자

네 가지 직무. 그를 위한 네 가지 프로필.

모든 워크스페이스는 추측이 아니라 눈앞의 작업에 맞게 설계된 프로필로 시작합니다 — 작업에 맞춰 CPU, 메모리, 스토리지를 설정하거나 직접 구성할 수 있습니다.

코드 및 빌드 프로필

DevOps 랩 프로필

AI 연구자

자신의 Mac에서 실행되는 모델을 대상으로, 격리된 환경에서 에이전트, 도구 호출, RAG 파이프라인을 구축하고 테스트하세요.

AI 샌드박스 + AI 브리지
가장 중요한 두 가지 기능

로컬 AI, 그리고 마음 놓고 버릴 수 있는 환경을 중심으로 만들었습니다.

AI 브리지 — 클라우드를 거치지 않는 로컬 모델 추론

Mac 자체 GPU에서 추론을 실행하고, 워크스페이스 내부에서 표준 chat-completions 엔드포인트로 그것에 접근하세요 — 어떤 로컬 서버에 접근하는 것과 똑같은 방식입니다. 머신을 절대 벗어나지 않는 모델을 대상으로 에이전트, 도구 호출, RAG 파이프라인을 구축하고 테스트하세요. API 키도, 사용 비용도 필요 없고, 데이터가 Mac 밖으로 나가지 않습니다.

  • Ollama 같은 로컬 모델 서버와 함께 작동
  • Velo Workspaces나 제3자에게 전송되는 것은 아무것도 없음
  • AI 샌드박스 프로필은 기본적으로 에이전트 프레임워크와 도구에 맞게 설정되어 있음

Mac mini(Apple M1)에서 측정

첫 토큰까지의 시간 280 ms 네이티브 310 ms AI 브리지 경유 +10%
처리량 12.75 tok/s 네이티브 12.27 tok/s AI 브리지 경유 −4%

Llama 3 기준, 호스트에서 직접(루프백) 실행한 경우와 AI 브리지를 통해 Linux 워크스페이스에서 접근한 경우를 각각 5회씩 측정해 평균낸 값입니다. 결과는 모델, Mac, 워크로드에 따라 달라집니다.

일회용 워크스페이스 — QA는 원래 이래야 합니다

정확히 한 번의 테스트 실행을 위한 깨끗한 환경을 실행하고, 닫는 순간 스스로 정리되게 하세요 — 지워야 할 스냅샷도 없고, “지난번에 뭔가 설치한 채로 남겨두지 않았나”라는, 통과한 테스트가 진짜인지 의심하게 만드는 걱정도 없습니다. 완전히 구성된 워크스페이스 — OS, 패키지, dotfiles, 전부 — 를 한 번 베이스 이미지로 봉인한 다음, copy-on-write를 이용해 몇 초 만에 그로부터 새 일회용 워크스페이스를 복제하면, 모든 테스트가 정확히 동일한, 검증된 상태에서 시작합니다.

  • 현재 상태를 재사용 가능한 베이스 이미지로 클릭 한 번에 저장
  • 즉시 복제 — 실행할 때마다 재설치할 필요 없음
  • 정리하고 싶을 때 언제든 환경설정에서 저장된 베이스 이미지 관리
그 밖에 기대할 만한 모든 것

실제 툴체인을 존중하는 통합 기능.

공유 폴더

호스트 폴더를 워크스페이스로 곧바로 공유 — macOS 게스트에서는 자동 마운트, Linux에서는 복사해 붙여넣을 수 있는 명령어 제공.

SSH & VS Code, 클릭 한 번으로

어떤 워크스페이스든 빠른 SSH 접속, 그리고 생성된 VS Code Remote-SSH 설정으로 게스트가 켜지는 즉시 에디터가 연결됩니다.

시리얼 콘솔

디스플레이를 전혀 띄우지 않는 Linux 게스트를 디버깅하기 위한 내장 터미널 — 외부 SSH 클라이언트 불필요.

클립보드 공유

자신의 데스크톱 창인 것처럼, Mac과 Linux 워크스페이스 사이에서 복사하고 붙여넣으세요.

Linux용 Rosetta 2

필요한 워크스페이스 안에서 x86_64 Linux 바이너리를 Apple 실리콘에서 거의 네이티브 속도로 실행하세요.

일시 중지 & 최대 절전

작업 도중 워크스페이스를 일시 중지하고, 백그라운드에서 계속 실행해 두지 않고도 정확히 그 지점부터 다시 시작하세요.

게스트 운영체제

정말 필요한 Linux를 실행하세요.

미러가 아니라 각 프로젝트의 공식 소스에서 직접 — 그리고 Metal 가속을 통한 거의 네이티브급 그래픽 성능의 macOS 게스트까지.

Ubuntu Desktop Ubuntu Server Debian Fedora Workstation Alpine Linux macOS guests

기본적으로 비공개, 기본적으로 로컬.

계정이 필요 없고, 워크스페이스가 하는 어떤 작업도 클라우드에 의존하지 않습니다. 진단 및 충돌 보고는 옵트인 방식이며 기본적으로 꺼져 있습니다. 게스트 OS, 파일, 모델까지 모든 것이 여러분의 Mac 안에 머뭅니다. 전체 개인정보 처리방침 보기.
