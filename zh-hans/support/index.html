入门指南

如何创建工作区

  1. 打开新建工作区

    在工作区库中选择新建工作区，然后选取镜像来源：官方镜像、现有虚拟磁盘，或已保存的基础镜像。

  2. 选择预设

    选择与你的工作匹配的预设——代码与构建、DevOps 实验室、AI 沙盒等——或者自行配置 CPU、内存和存储。

  3. 确认并启动

    确认摘要信息，然后开始安装（如果是从基础镜像克隆，则为启动）。官方镜像会在你首次使用时直接从该项目自己的源下载。

如何使用用后即焚工作区

  1. 将工作区标记为用后即焚

    创建工作区时打开用后即焚选项——最好搭配基础镜像使用，这样能立即从已验证可用的状态启动。

  2. 仅用于一项任务

    运行你的测试、复现 bug，或尝试有风险的命令——把这个工作区当作完全可以丢弃的对象。

  3. 关闭它

    关闭一个用后即焚工作区会自动将其删除，包括磁盘在内。之后无需清理，也无法恢复——不要把用后即焚工作区用于任何你需要保留的东西。

常见问题

共享文件夹

如何从工作区内部访问共享文件夹？

macOS 工作区（macOS 13 或更高版本）：共享文件夹会自动挂载——打开访达（Finder），查看 /Volumes/My Shared Files路径下的内容。无需任何命令。

Linux 工作区：每个共享文件夹都有自己的挂载命令，会直接显示在应用内该工作区的「共享文件」标签页中，使用该文件夹专属的标签，形如：

mkdir -p /mnt/my_folder
sudo mount -t virtiofs <folder-tag-shown-in-app> /mnt/my_folder

请使用应用中显示的确切标签——每个文件夹的标签都是唯一的，因此从别处复制的命令不会生效。

剪贴板与输入

Mac 与 Linux 工作区之间的复制粘贴不生效

Linux 上的剪贴板共享依赖于虚拟机内运行的代理程序。请按顺序检查以下几点：

  1. 在工作区的「资源」标签页中，确认 剪贴板共享 已打开。
  2. 在虚拟机内，确认 spice-vdagent 已安装： 
    sudo apt install spice-vdagent
  3. 确认该代理程序确实在运行： 
    systemctl status spice-vdagentd
    如果处于未激活状态，用 sudo systemctl start spice-vdagentd启动它；如果你使用的是图形桌面环境，请注销后重新登录，以便桌面会话识别它。
  4. 某些精简版或无图形界面的桌面环境不会自动启动 spice-vdagent ——如果代理程序已安装并运行，但仍然不生效，请检查你桌面环境的自启动设置。

剪贴板共享目前仅适用于 Linux 工作区。

Rosetta（在 Apple 芯片上运行 x86_64）

如何在 Debian 工作区中启用 Rosetta？

Debian 使用与 Ubuntu 相同的 apt 和 update-binfmts 工具。在工作区的「资源」标签页中打开 Rosetta，启动该工作区，然后在虚拟机内执行一次以下命令：

sudo mkdir -p /media/rosetta
sudo mount -t virtiofs rosetta /media/rosetta

sudo apt-get update
sudo apt-get install -y binfmt-support

sudo /usr/sbin/update-binfmts --install rosetta /media/rosetta/rosetta \
  --magic "\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x3e\x00" \
  --mask "\xff\xff\xff\xff\xff\xfe\xfe\x00\xff\xff\xff\xff\xff\xff\xff\xff\xfe\xff\xff\xff" \
  --credentials yes --preserve yes --fix-binary yes
如何在 Fedora 工作区中启用 Rosetta？

Fedora 没有自带 Debian 的 update-binfmts 工具，但自带了 systemd-binfmt，它会从配置文件中读取与前者完全相同的内核 binfmt_misc 注册信息。在工作区的「资源」标签页中打开 Rosetta，启动该工作区，然后在虚拟机内执行一次以下命令：

sudo mkdir -p /media/rosetta
sudo mount -t virtiofs rosetta /media/rosetta

sudo mkdir -p /etc/binfmt.d
sudo tee /etc/binfmt.d/rosetta.conf > /dev/null <<'EOF'
:rosetta:M::\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x3e\x00:\xff\xff\xff\xff\xff\xfe\xfe\x00\xff\xff\xff\xff\xff\xff\xff\xff\xfe\xff\xff\xff:/media/rosetta/rosetta:CF
EOF

sudo systemctl restart systemd-binfmt

rosetta.conf 文件会在重启后依然保留，因此每个工作区只需设置一次。

AI 桥接

如何将 AI 桥接连接到 Ollama？
  1. 在工作区之外，于你的 Mac 上安装并运行 Ollama。
  2. 为该工作区启用 AI 桥接（在 AI 沙盒预设中默认开启，也可以自行在工作区的「集成」或「资源」设置中打开）。
  3. 启动工作区，然后打开它的 AI 桥接标签页——其中会显示本地端点地址，对于 Linux 虚拟机，还会显示转发连接所需的确切命令。
  4. 在工作区内，把你的工具指向这个地址，就像连接任何使用标准 chat-completions API 格式的本地服务器一样。

用后即焚工作区与基础镜像

关闭用后即焚工作区后会发生什么？

关闭的瞬间它会被自动删除，包括其磁盘。之后无法恢复——不要把用后即焚工作区用于任何你需要保留的东西。

如何把一个工作区变成可复用的基础镜像？

停止该工作区，然后在已停止工作区显示的横幅中选择 保存为基础镜像 。之后再次保存同一个工作区会创建一个新的独立基础镜像，而不是覆盖之前的镜像——你可以在偏好设置 → 基础镜像中管理并删除不再需要的基础镜像。

我的工作区和基础镜像存储在哪里？如何释放空间？

工作区磁盘和基础镜像存放在你 Mac 上的 ~/Library/Application Support/VeloWorkspaces 目录下。从库中删除不再需要的工作区，并在偏好设置 → 基础镜像中删除未使用的基础镜像，即可释放空间。

常规问题

Velo Workspaces 支持 Windows 虚拟机吗？

此版本尚不支持。Velo Workspaces 目前支持 Linux 和 macOS 虚拟机。

为什么工作区运行时无法更改某些设置？

CPU、内存、存储、共享文件夹等一些设置属于虚拟机配置的一部分，运行期间无法更改（Apple 的 Virtualization 框架不支持对这些项目进行热插拔）。请先停止该工作区，完成更改后再重新启动。

为什么我无法创建 macOS 虚拟机？

创建 macOS 虚拟机需要以 Apple 芯片 Mac 作为主机。在 Intel Mac 上，Linux 虚拟机仍然完全受支持。
