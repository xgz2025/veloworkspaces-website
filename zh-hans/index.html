AI 沙盒 + AI 桥接
最重要的两项功能

围绕本地 AI，以及你可以放心丢弃的环境而打造。

AI 桥接——本地模型推理，无需接入云端

在 Mac 自身的 GPU 上运行推理，并以标准的 chat-completions 接口从工作区内部访问它——就像访问任何本地服务器一样。构建与测试智能体、工具调用和 RAG 流水线，对接一个始终不离开这台机器的模型。无需 API 密钥，无使用费用，数据不出 Mac。

  • 可搭配 Ollama 等本地模型服务器使用
  • 不会向 Velo Workspaces 或任何第三方发送任何内容
  • AI 沙盒预设默认即为智能体框架与相关工具预留了合适的资源

用后即焚工作区——QA 本该如此

为一次测试运行启动一个干净的环境，关闭它的瞬间就自动清理干净——不用记着删快照，也不必怀疑「上次是不是装了什么东西没清干净」，进而怀疑测试结果是否真实可信。把一个配置完整的工作区——操作系统、软件包、点文件（dotfiles），一切——一次性封存为基础镜像，之后用写时复制（copy-on-write）在几秒钟内从中克隆出新的用后即焚工作区，让每次测试都从完全相同、已验证可用的状态开始。

  • 一键将当前状态保存为可复用的基础镜像
  • 即时克隆——无需在每次运行前重新安装
  • 随时在偏好设置中管理已保存的基础镜像，需要时清理
其他你所期待的一切

尊重你真实工具链的集成功能。

共享文件夹

将主机文件夹直接共享进工作区——macOS 虚拟机自动挂载，Linux 则提供可复制粘贴的挂载命令。

SSH 与 VS Code，一键直达

快速 SSH 访问任意工作区，并自动生成 VS Code Remote-SSH 配置，虚拟机一启动编辑器即可连接。

串口控制台

内置终端，用于调试从不启动图形界面的 Linux 虚拟机——无需外部 SSH 客户端。

剪贴板共享

在 Mac 与 Linux 工作区之间复制粘贴，就像操作自己桌面上的一个窗口。

面向 Linux 的 Rosetta 2

在需要的工作区内，让 x86_64 Linux 程序在 Apple 芯片上以接近原生的速度运行。

暂停与休眠

在任务进行中暂停工作区，之后从原处继续，无需让它在后台持续运行。
