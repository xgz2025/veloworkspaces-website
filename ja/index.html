Apple シリコン搭載 Mac 向け

使い捨てで再現可能な仮想マシン——おもちゃの VM アプリではありません。

Velo Workspaces は、AI 研究者、QA エンジニア、DevOps プロフェッショナル、ソフトウェアエンジニアが実際にどう働くかを軸に作られた、本物の分離された Linux と macOS の VM を Mac 上で実行します——ありきたりな「別の OS を動かす」目新しさではありません。

App Store でダウンロード 何のために作られたか見る

Apple シリコン搭載 Mac、macOS 14 以降。アカウント不要。クラウド依存なし。

対象ユーザー

4つの仕事。そのために作られた4つのプロファイル。

どのワークスペースも、当てずっぽうではなく目の前の仕事に合わせて設計されたプロファイルから始まります——CPU、メモリ、ストレージを仕事に合わせて設定するか、自分で構成することもできます。

ソフトウェアエンジニア

メインマシンに触れることなく、クリーンなツールチェーンでビルド・テストできます——または同僚とまったく同じセットアップを正確に再現できます。

コード & ビルドプロファイル

QA エンジニア

すべてのテストをまったく同じ動作確認済みイメージから実行し、その後 VM を破棄——覚えておくべきスナップショットも、疑うべき残存状態もありません。

使い捨てワークスペース

DevOps プロフェッショナル

デプロイスクリプト、インストール手順、設定変更を、本番投入前に本物の分離された Linux VM で検証できます。

DevOps ラボプロファイル

AI 研究者

自分の Mac 上で動くモデルに対して、隔離された VM の中でエージェント、ツール呼び出し、RAG パイプラインを構築・テストできます。

AI サンドボックス + AI ブリッジ
最も重要な2つの機能

ローカル AI を中心に、そして気兼ねなく捨てられる環境を中心に。

AI ブリッジ——ローカルモデル推論、クラウドを介さない

Mac 自身の GPU で推論を実行し、ワークスペース内から標準的な chat-completions エンドポイントとしてアクセスできます——どんなローカルサーバーにアクセスするのとも同じ感覚です。マシンを一切離れないモデルに対してエージェント、ツール呼び出し、RAG パイプラインを構築・テストできます。API キー不要、利用コスト不要、データは Mac の外に出ません。

  • Ollama などのローカルモデルサーバーで動作
  • Velo Workspaces や第三者に送信されるものは一切なし
  • AI サンドボックスプロファイルは、標準でエージェントフレームワークやツール向けにサイズ設定済み

Mac mini（Apple M1）で測定

最初のトークンまでの時間 280 ms ネイティブ 310 ms AI ブリッジ経由 +10%
スループット 12.75 tok/s ネイティブ 12.27 tok/s AI ブリッジ経由 −4%

Llama 3 を使用し、ホスト上（ループバック）での直接実行と、AI ブリッジ経由で Linux ワークスペースから到達した場合をそれぞれ5回ずつ計測して平均。結果はモデル、Mac、ワークロードにより変動します。

使い捨てワークスペース——QA はこうあるべき

1回のテスト実行のためだけにクリーンな VM を立ち上げ、閉じた瞬間に自動でクリーンアップさせる——削除を忘れがちなスナップショットも、「前回何かインストールしたまま残っていないか」というテスト結果の信頼性を揺るがす疑念もありません。OS、パッケージ、dotfiles まで含めて完全に構成されたワークスペースを一度だけベースイメージとして封印し、そこから copy-on-write で数秒のうちに新しい使い捨てワークスペースを複製すれば、すべてのテストがまったく同じ、動作確認済みの状態から始まります。

  • 現在の状態をワンクリックで再利用可能なベースイメージとして保存
  • 即座に複製——毎回の実行前に再インストール不要
  • 片付けたいときはいつでも環境設定から保存済みベースイメージを管理

その他、期待通りのすべて

実際のツールチェーンを尊重する統合機能。

共有フォルダ

ホストのフォルダをそのままワークスペースに共有——macOS ゲストでは自動マウント、Linux にはコピー & ペースト可能なコマンドを用意。

SSH & VS Code、ワンクリックで

どのワークスペースにもすばやい SSH アクセス、さらに生成される VS Code Remote-SSH 設定で、ゲストが起動した瞬間にエディタが接続。

シリアルコンソール

ディスプレイを一切起動しない Linux ゲストをデバッグするための内蔵ターミナル——外部の SSH クライアント不要。

クリップボード共有

自分のデスクトップのウィンドウのように、Mac と Linux ワークスペースの間でコピー & ペースト。

Linux 向け Rosetta 2

必要とするワークスペース内で、x86_64 の Linux バイナリを Apple シリコン上でほぼネイティブな速度で実行。

一時停止 & 休止

作業途中でワークスペースを一時停止し、バックグラウンドで動かし続けることなく、まさにその続きから再開。

ゲスト OS

本当に必要な Linux VM を実行する。

ミラーではなく各プロジェクトの公式ソースから直接取得——さらに Metal アクセラレーションによるほぼネイティブなグラフィックスを備えた macOS ゲストも利用可能。
