Support

Erste Schritte und Antworten auf häufige Fragen.

Nicht gefunden, wonach Sie suchen? Schreiben Sie an support@veloworkspaces.com und wir helfen Ihnen direkt weiter.

Erste Schritte

So erstellen Sie einen Arbeitsbereich

  1. Neuen Arbeitsbereich öffnen

    Wählen Sie in der Arbeitsbereich-Bibliothek Neuer Arbeitsbereich und dann eine Image-Quelle: ein offizielles Image, eine vorhandene virtuelle Festplatte oder ein gespeichertes Basis-Image.

  2. Profil auswählen

    Wählen Sie das Profil, das zu Ihrer Arbeit passt — Code & Build, DevOps-Labor, KI-Sandbox und mehr — oder konfigurieren Sie CPU, Arbeitsspeicher und Speicherplatz selbst.

  3. Prüfen und starten

    Bestätigen Sie die Zusammenfassung und starten Sie dann die Installation (oder den Start, bei einem Klon eines Basis-Images). Offizielle Images werden beim ersten Gebrauch direkt von der eigenen Quelle des jeweiligen Projekts heruntergeladen.

So nutzen Sie Einweg-Arbeitsbereiche

  1. Einen Arbeitsbereich als Einweg markieren

    Aktivieren Sie beim Erstellen eines Arbeitsbereichs die Einweg-Option — am besten kombiniert mit einem Basis-Image, damit er sofort in einem bekannt guten Zustand startet.

  2. Für genau eine Aufgabe verwenden

    Führen Sie Ihren Test aus, reproduzieren Sie den Fehler, oder probieren Sie den riskanten Befehl aus — behandeln Sie den Arbeitsbereich als vollständig entbehrlich.

  3. Schließen

    Das Schließen eines Einweg-Arbeitsbereichs löscht ihn automatisch, inklusive Festplatte. Danach gibt es nichts aufzuräumen und nichts wiederherzustellen — verwenden Sie Einweg-Arbeitsbereiche nicht für etwas, das Sie behalten müssen.

Häufig gestellte Fragen

Gemeinsame Ordner

Wie greife ich von innerhalb eines Arbeitsbereichs auf den gemeinsamen Ordner zu?

macOS-Arbeitsbereiche (macOS 13 oder neuer): Gemeinsame Ordner werden automatisch eingebunden — öffnen Sie den Finder und schauen Sie unter /Volumes/My Shared Files nach. Kein Befehl nötig.

Linux-Arbeitsbereiche: Jeder gemeinsame Ordner erhält seinen eigenen Einbindungsbefehl, der direkt in der App unter dem Tab „Freigegebene Dateien“ des Arbeitsbereichs angezeigt wird. Er sieht so aus, mit dem eigenen Tag dieses Ordners:

mkdir -p /mnt/my_folder
sudo mount -t virtiofs <folder-tag-shown-in-app> /mnt/my_folder

Verwenden Sie genau das in der App angezeigte Tag — es ist pro Ordner eindeutig, sodass das Kopieren eines Befehls von anderswo nicht funktioniert.

Zwischenablage & Eingabe

Kopieren und Einfügen funktioniert nicht zwischen meinem Mac und einem Linux-Arbeitsbereich

Die Zwischenablage-Freigabe unter Linux hängt von einem im Gast laufenden Agenten ab. Gehen Sie diese Schritte der Reihe nach durch:

  1. Bestätigen Sie im Resources-Tab des Arbeitsbereichs, dass Zwischenablage-Freigabe aktiviert ist.
  2. Stellen Sie im Gast sicher, dass spice-vdagent installiert ist: 
    sudo apt install spice-vdagent
  3. Bestätigen Sie, dass der Agent tatsächlich läuft: 
    systemctl status spice-vdagentd
    Falls er inaktiv ist, starten Sie ihn mit sudo systemctl start spice-vdagentd, und melden Sie sich, falls Sie eine grafische Desktop-Umgebung nutzen, ab und wieder an, damit die Desktop-Sitzung ihn erkennt.
  4. Manche minimalen oder headless Desktop-Umgebungen starten spice-vdagent nicht automatisch — prüfen Sie die Autostart-Einstellungen Ihrer Desktop-Umgebung, falls es weiterhin nicht funktioniert, nachdem der Agent installiert ist und läuft.

Die Zwischenablage-Freigabe funktioniert derzeit nur für Linux-Arbeitsbereiche.

Rosetta (x86_64 auf Apple Silicon)

Wie aktiviere ich Rosetta in einem Debian-Arbeitsbereich?

Debian nutzt dieselben apt und update-binfmts Werkzeuge wie Ubuntu. Aktivieren Sie Rosetta für den Arbeitsbereich im Resources-Tab, starten Sie den Arbeitsbereich, und führen Sie dann einmalig Folgendes im Gast aus:

sudo mkdir -p /media/rosetta
sudo mount -t virtiofs rosetta /media/rosetta

sudo apt-get update
sudo apt-get install -y binfmt-support

sudo /usr/sbin/update-binfmts --install rosetta /media/rosetta/rosetta \
  --magic "\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x3e\x00" \
  --mask "\xff\xff\xff\xff\xff\xfe\xfe\x00\xff\xff\xff\xff\xff\xff\xff\xff\xfe\xff\xff\xff" \
  --credentials yes --preserve yes --fix-binary yes
Wie aktiviere ich Rosetta in einem Fedora-Arbeitsbereich?

Fedora liefert Debians update-binfmts Tool nicht mit, wohl aber systemd-binfmt, das über eine Konfigurationsdatei exakt dieselbe Kernel- binfmt_misc -Registrierung liest. Aktivieren Sie Rosetta für den Arbeitsbereich im Resources-Tab, starten Sie den Arbeitsbereich, und führen Sie dann einmalig Folgendes im Gast aus:

sudo mkdir -p /media/rosetta
sudo mount -t virtiofs rosetta /media/rosetta

sudo mkdir -p /etc/binfmt.d
sudo tee /etc/binfmt.d/rosetta.conf > /dev/null <<'EOF'
:rosetta:M::\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x3e\x00:\xff\xff\xff\xff\xff\xfe\xfe\x00\xff\xff\xff\xff\xff\xff\xff\xff\xfe\xff\xff\xff:/media/rosetta/rosetta:CF
EOF

sudo systemctl restart systemd-binfmt

Die Datei rosetta.conf bleibt über Neustarts hinweg bestehen — dies ist also eine einmalige Einrichtung pro Arbeitsbereich.

AI Bridge

Wie verbinde ich AI Bridge mit Ollama?
  1. Installieren und starten Sie Ollama auf Ihrem Mac, außerhalb des Arbeitsbereichs.
  2. Aktivieren Sie AI Bridge für den Arbeitsbereich (standardmäßig aktiv im KI-Sandbox-Profil, oder selbst in den Integrations- bzw. Resources-Einstellungen des Arbeitsbereichs aktivieren).
  3. Starten Sie den Arbeitsbereich und öffnen Sie dann dessen AI-Bridge-Tab — er zeigt die lokale Endpunktadresse und, bei einem Linux-Gast, die genauen Befehle zur Weiterleitung der Verbindung.
  4. Richten Sie Ihre Werkzeuge innerhalb des Arbeitsbereichs auf diese Adresse, genauso wie Sie es bei jedem lokalen Server tun würden, der das gängige Chat-Completions-API-Format spricht.

Einweg-Arbeitsbereiche & Basis-Images

Was passiert mit einem Einweg-Arbeitsbereich, wenn ich ihn schließe?

Er wird automatisch in dem Moment gelöscht, in dem Sie ihn schließen, inklusive Festplatte. Danach gibt es nichts wiederherzustellen — verwenden Sie einen Einweg-Arbeitsbereich nicht für etwas, das Sie behalten müssen.

Wie mache ich aus einem Arbeitsbereich ein wiederverwendbares Basis-Image?

Stoppen Sie den Arbeitsbereich und wählen Sie dann Als Basis-Image speichern aus dem Banner, das bei einem gestoppten Arbeitsbereich angezeigt wird. Speichern Sie denselben Arbeitsbereich später erneut, entsteht ein neues, unabhängiges Basis-Image, statt das vorherige zu überschreiben — verwalten und löschen Sie nicht mehr benötigte Basis-Images unter Einstellungen → Basis-Images.

Wo werden meine Arbeitsbereiche und Basis-Images gespeichert, und wie schaffe ich Speicherplatz frei?

Arbeitsbereich-Festplatten und Basis-Images liegen unter ~/Library/Application Support/VeloWorkspaces auf Ihrem Mac. Löschen Sie nicht mehr benötigte Arbeitsbereiche aus der Bibliothek und ungenutzte Basis-Images unter Einstellungen → Basis-Images, um Speicherplatz freizugeben.

Allgemein

Unterstützt Velo Workspaces Windows-Gäste?

Nicht in dieser Version. Velo Workspaces unterstützt derzeit Linux- und macOS-Gäste.

Warum kann ich manche Einstellungen nicht ändern, während ein Arbeitsbereich läuft?

CPU, Arbeitsspeicher, Speicherplatz, gemeinsame Ordner und einige andere Einstellungen sind Teil der Konfiguration der virtuellen Maschine und können nicht geändert werden, während sie läuft (Apples Virtualization-Framework unterstützt kein Hot-Plugging dafür). Stoppen Sie den Arbeitsbereich, nehmen Sie die Änderung vor, und starten Sie ihn erneut.

Warum kann ich keinen macOS-Gast erstellen?

macOS-Gäste erfordern einen Apple-Silicon-Mac als Host. Auf einem Intel-Mac werden Linux-Gäste weiterhin vollständig unterstützt.
