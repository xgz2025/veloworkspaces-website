Für Apple-Silicon-Macs

Wegwerfbare, reproduzierbare Umgebungen — kein Spielzeug-VM-Tool.

Velo Workspaces führt echte, isolierte Linux- und macOS-Umgebungen auf Ihrem Mac aus, gebaut danach, wie KI-Forscher, QA-Ingenieure, DevOps-Profis und Softwareentwickler tatsächlich arbeiten — keine generische „ein weiteres Betriebssystem starten“-Spielerei.

Bald verfügbar imApp Store Ansehen, wofür es gebaut ist

macOS 14 oder neuer auf Apple Silicon. Kein Konto. Keine Cloud-Abhängigkeit.

Für wen

Vier Aufgaben. Vier dafür gebaute Profile.

Jeder Arbeitsbereich startet mit einem Profil, das auf die anstehende Aufgabe zugeschnitten ist, statt geraten zu sein — CPU, Arbeitsspeicher und Speicherplatz passend zur Aufgabe, oder konfigurieren Sie Ihr eigenes.

Softwareentwickler

Entwickeln und testen mit einer sauberen Toolchain, ohne Ihre Hauptmaschine anzurühren — oder das exakte Setup eines Kollegen, originalgetreu reproduziert.

Profil Code & Build

QA-Ingenieure

Führen Sie jeden Test aus genau demselben bekannt guten Image aus und werfen Sie die Umgebung danach weg — kein Snapshot, an den Sie sich erinnern müssen, kein Restzustand, an dem Sie zweifeln müssen.

Einweg-Arbeitsbereiche

DevOps-Profis

Prüfen Sie ein Deployment-Skript, eine Installationsroutine oder eine Konfigurationsänderung an einem echten, isolierten Linux-Host, bevor sie live geht.

Profil DevOps-Labor

KI-Forscher

Bauen und testen Sie Agenten, Tool-Calling und RAG-Pipelines in einer isolierten Umgebung, gegen ein Modell, das auf Ihrem eigenen Mac läuft.

KI-Sandbox + AI Bridge
Die zwei wichtigsten Funktionen

Gebaut um lokale KI — und Umgebungen, die Sie sich leisten können wegzuwerfen.

AI Bridge — lokale Modellinferenz, ohne Cloud im Spiel

Führen Sie Inferenz auf der GPU Ihres Mac aus und erreichen Sie sie von innerhalb eines Arbeitsbereichs als gewöhnlichen Chat-Completions-Endpunkt — genau so, wie Sie jeden lokalen Server erreichen würden. Bauen und testen Sie Agenten, Tool-Calling und RAG-Pipelines gegen ein Modell, das die Maschine nie verlässt. Keine API-Schlüssel, keine Nutzungskosten, keine Daten verlassen Ihren Mac.

  • Funktioniert mit lokalen Modell-Servern wie Ollama
  • Nichts wird an Velo Workspaces oder Dritte gesendet
  • Das KI-Sandbox-Profil ist von Haus aus auf Agenten-Frameworks und Tooling zugeschnitten

Gemessen auf einem Mac mini (Apple M1)

Zeit bis zum ersten Token 280 ms nativ 310 ms über AI Bridge +10 %
Durchsatz 12,75 Tok/s nativ 12,27 Tok/s über AI Bridge −4 %

Llama 3, direkt auf dem Host (Loopback) verglichen mit dem Zugriff aus einem Linux-Arbeitsbereich über AI Bridge — gemittelt über je 5 Läufe. Ergebnisse variieren je nach Modell, Mac und Workload.

Einweg-Arbeitsbereiche — so sollte QA funktionieren

Starten Sie eine saubere Umgebung für genau einen Testlauf, und lassen Sie sie sich selbst aufräumen, sobald Sie sie schließen — kein Snapshot, an dessen Löschen Sie sich erinnern müssen, kein Zweifel nach dem Motto „Moment, hab ich da beim letzten Mal was installiert liegen lassen“. Versiegeln Sie einen vollständig eingerichteten Arbeitsbereich — Betriebssystem, Pakete, Dotfiles, alles — einmal zu einem Basis-Image, und klonen Sie dann in Sekunden neue Einweg-Arbeitsbereiche daraus per Copy-on-Write, sodass jeder Test vom exakt gleichen, bekannt guten Zustand startet.

  • Ein Klick, um den aktuellen Zustand als wiederverwendbares Basis-Image zu speichern
  • Sofortiges Klonen — keine Neuinstallation vor jedem Lauf
  • Gespeicherte Basis-Images jederzeit in den Einstellungen verwalten und aufräumen
Alles andere, was Sie erwarten würden

Integrationen, die Ihre tatsächliche Toolchain respektieren.

Gemeinsame Ordner

Teilen Sie Host-Ordner direkt in einen Arbeitsbereich — bei macOS-Gästen automatisch eingebunden, mit einem Copy-Paste-Befehl für Linux.

SSH & VS Code, einen Klick entfernt

Schneller SSH-Zugriff auf jeden Arbeitsbereich, plus eine generierte VS-Code-Remote-SSH-Konfiguration, sodass Ihr Editor sich verbindet, sobald der Gast bereit ist.

Serielle Konsole

Eine eingebaute Konsole zum Debuggen eines Linux-Gasts, der nie ein Display hochfährt — kein externer SSH-Client nötig.

Zwischenablage-Freigabe

Kopieren und Einfügen zwischen Ihrem Mac und einem Linux-Arbeitsbereich, als wäre es ein Fenster auf Ihrem eigenen Desktop.

Rosetta 2 für Linux

Führen Sie x86_64-Linux-Binärdateien mit nahezu nativer Geschwindigkeit auf Apple Silicon aus, innerhalb des Arbeitsbereichs, der sie benötigt.

Pausieren & Ruhezustand

Pausieren Sie einen Arbeitsbereich mitten in der Arbeit und machen Sie genau dort weiter, wo Sie aufgehört haben — ohne ihn im Hintergrund laufen zu lassen.

Gast-Betriebssysteme

Führen Sie das Linux aus, das Sie wirklich brauchen.

Direkt von der offiziellen Quelle jedes Projekts bezogen, nie von einem Mirror — zusammen mit macOS-Gästen mit nahezu nativer, Metal-beschleunigter Grafik.

Privat und lokal per Standard.

Kein Konto, keine Cloud-Abhängigkeit für irgendetwas, was ein Arbeitsbereich tut. Diagnose und Absturzberichte sind Opt-in und standardmäßig deaktiviert. Alles — das Gast-Betriebssystem, Ihre Dateien, Ihre Modelle — bleibt auf Ihrem Mac. Lesen Sie die vollständige Datenschutzerklärung.
