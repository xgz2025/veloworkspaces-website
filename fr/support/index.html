Support

Prise en main, et réponses aux questions fréquentes.

Vous ne trouvez pas ce que vous cherchez ? Écrivez à support@veloworkspaces.com et nous vous aiderons directement.

Prise en main

Comment créer un espace de travail

  1. Ouvrir Nouvel espace de travail

    Depuis la bibliothèque d'espaces de travail, choisissez Nouvel espace de travail et sélectionnez une source d'image : une image officielle, un disque virtuel existant, ou une image de base enregistrée.

  2. Choisir un profil

    Choisissez le profil qui correspond à votre travail — Code & Compilation, Labo DevOps, Bac à sable IA, et plus — ou configurez vous-même le CPU, la mémoire et le stockage.

  3. Vérifier et lancer

    Confirmez le résumé, puis démarrez l'installation (ou le démarrage, pour un clone d'image de base). Les images officielles sont téléchargées directement depuis la source propre de ce projet la première fois que vous les utilisez.

Comment utiliser les espaces de travail jetables

  1. Marquer un espace de travail comme jetable

    Lors de la création d'un espace de travail, activez l'option jetable — idéalement associée à une image de base pour qu'il démarre instantanément depuis un état fiable et connu.

  2. L'utiliser pour exactement une tâche

    Lancez votre test, reproduisez le bug, ou essayez la commande risquée — traitez l'espace de travail comme entièrement jetable.

  3. Le fermer

    Fermer un espace de travail jetable le supprime automatiquement, disque compris. Il n'y a rien à nettoyer ensuite, et rien à récupérer — n'utilisez pas les espaces de travail jetables pour quoi que ce soit que vous devez conserver.

Questions fréquentes

Dossiers partagés

Comment accéder au dossier partagé depuis un espace de travail ?

Espaces de travail macOS (macOS 13 ou ultérieur) : les dossiers partagés se montent automatiquement — ouvrez le Finder et cherchez sous /Volumes/My Shared Files. Aucune commande nécessaire.

Espaces de travail Linux : chaque dossier partagé a sa propre commande de montage, affichée directement dans l'application sous l'onglet Fichiers partagés de l'espace de travail. Elle ressemble à ceci, en utilisant le tag propre de ce dossier :

mkdir -p /mnt/my_folder
sudo mount -t virtiofs <folder-tag-shown-in-app> /mnt/my_folder

Utilisez exactement le tag affiché dans l'application — il est unique par dossier, donc copier une commande venant d'ailleurs ne fonctionnera pas.

Presse-papiers & saisie

Le copier-coller ne fonctionne pas entre mon Mac et un espace de travail Linux

Le partage du presse-papiers sous Linux dépend d'un agent exécuté dans l'invité. Suivez ces étapes dans l'ordre :

  1. Dans l'onglet Ressources de l'espace de travail, vérifiez que Partage du presse-papiers est activé.
  2. Dans l'invité, assurez-vous que spice-vdagent est installé : 
    sudo apt install spice-vdagent
  3. Vérifiez que l'agent est bien en cours d'exécution : 
    systemctl status spice-vdagentd
    S'il est inactif, démarrez-le avec sudo systemctl start spice-vdagentd, et si vous êtes sur un bureau graphique, déconnectez-vous et reconnectez-vous pour que la session de bureau le prenne en compte.
  4. Certains environnements de bureau minimaux ou headless ne lancent pas automatiquement spice-vdagent — vérifiez les paramètres de démarrage automatique de votre environnement de bureau si cela ne fonctionne toujours pas une fois l'agent installé et en cours d'exécution.

Le partage du presse-papiers fonctionne actuellement uniquement pour les espaces de travail Linux.

Rosetta (x86_64 sur Apple Silicon)

Comment activer Rosetta dans un espace de travail Debian ?

Debian utilise les mêmes outils apt et update-binfmts qu'Ubuntu. Activez Rosetta pour l'espace de travail dans son onglet Ressources, démarrez l'espace de travail, puis exécutez ceci une fois dans l'invité :

sudo mkdir -p /media/rosetta
sudo mount -t virtiofs rosetta /media/rosetta

sudo apt-get update
sudo apt-get install -y binfmt-support

sudo /usr/sbin/update-binfmts --install rosetta /media/rosetta/rosetta \
  --magic "\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x3e\x00" \
  --mask "\xff\xff\xff\xff\xff\xfe\xfe\x00\xff\xff\xff\xff\xff\xff\xff\xff\xfe\xff\xff\xff" \
  --credentials yes --preserve yes --fix-binary yes
Comment activer Rosetta dans un espace de travail Fedora ?

Fedora n'embarque pas l'outil update-binfmts de Debian, mais il embarque systemd-binfmt, qui lit exactement le même enregistrement noyau binfmt_misc depuis un fichier de configuration. Activez Rosetta pour l'espace de travail dans son onglet Ressources, démarrez l'espace de travail, puis exécutez ceci une fois dans l'invité :

sudo mkdir -p /media/rosetta
sudo mount -t virtiofs rosetta /media/rosetta

sudo mkdir -p /etc/binfmt.d
sudo tee /etc/binfmt.d/rosetta.conf > /dev/null <<'EOF'
:rosetta:M::\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x3e\x00:\xff\xff\xff\xff\xff\xfe\xfe\x00\xff\xff\xff\xff\xff\xff\xff\xff\xfe\xff\xff\xff:/media/rosetta/rosetta:CF
EOF

sudo systemctl restart systemd-binfmt

Le fichier rosetta.conf persiste après redémarrage, il s'agit donc d'une configuration unique par espace de travail.

Pont IA

Comment connecter Pont IA à Ollama ?
  1. Installez et exécutez Ollama sur votre Mac, en dehors de l'espace de travail.
  2. Activez Pont IA pour l'espace de travail (activé par défaut dans le profil Bac à sable IA, ou activez-le vous-même dans les paramètres Intégrations ou Ressources de l'espace de travail).
  3. Démarrez l'espace de travail, puis ouvrez son onglet Pont IA — il affiche l'adresse du point de terminaison local et, pour un invité Linux, les commandes exactes pour transférer la connexion.
  4. Dans l'espace de travail, pointez vos outils vers cette adresse exactement comme vous le feriez pour n'importe quel serveur local qui parle le format d'API chat-completions standard.

Espaces de travail jetables & images de base

Que devient un espace de travail jetable quand je le ferme ?

Il est supprimé automatiquement dès que vous le fermez, disque compris. Il n'y a rien à récupérer ensuite — n'utilisez pas un espace de travail jetable pour quoi que ce soit que vous devez conserver.

Comment transformer un espace de travail en image de base réutilisable ?

Arrêtez l'espace de travail, puis choisissez Enregistrer comme image de base depuis la bannière affichée sur un espace de travail arrêté. Enregistrer à nouveau le même espace de travail plus tard crée une nouvelle image de base indépendante plutôt que d'écraser la précédente — gérez et supprimez les images de base dont vous n'avez plus besoin depuis Préférences → Images de base.

Où sont stockés mes espaces de travail et images de base, et comment libérer de l'espace ?

Les disques des espaces de travail et les images de base se trouvent sous ~/Library/Application Support/VeloWorkspaces sur votre Mac. Supprimez de la bibliothèque les espaces de travail dont vous n'avez plus besoin, et les images de base inutilisées depuis Préférences → Images de base, pour libérer de l'espace.

Général

Velo Workspaces prend-il en charge les invités Windows ?

Pas dans cette version. Velo Workspaces prend actuellement en charge les invités Linux et macOS.

Pourquoi ne puis-je pas modifier certains paramètres pendant qu'un espace de travail est en cours d'exécution ?

Le CPU, la mémoire, le stockage, les dossiers partagés et quelques autres paramètres font partie de la configuration de la machine virtuelle et ne peuvent pas être modifiés pendant son exécution (le framework Virtualization d'Apple ne prend pas en charge leur modification à chaud). Arrêtez l'espace de travail, effectuez le changement, puis redémarrez-le.

Pourquoi ne puis-je pas créer un invité macOS ?

Les invités macOS nécessitent un Mac Apple Silicon comme hôte. Sur un Mac Intel, les invités Linux restent entièrement pris en charge.
