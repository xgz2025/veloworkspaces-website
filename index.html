The two features that matter most

Built around local AI, and environments you can afford to throw away.

AI Bridge — local model inference, no cloud in the loop

Run inference on your Mac's own GPU and reach it from inside a workspace as a plain OpenAI-compatible endpoint — the same way you'd reach any local server. Build and test agents, tool-calling, and RAG pipelines against a model that never leaves the machine. No API keys, no usage costs, no data leaving your Mac.

  • Works with local model servers such as Ollama
  • Nothing is sent to Velo Workspaces or any third party
  • AI Sandbox profile is sized for agent frameworks and tooling out of the box

Disposable Workspaces — the way QA is supposed to work

Spin up a clean environment for exactly one test run, and let it clean up after itself the moment you close it — no snapshot to remember to delete, no "wait, did I leave something installed from last time" doubt about whether a pass is real. Seal a fully configured workspace — OS, packages, dotfiles, everything — into a base image once, then clone new disposable workspaces from it in seconds using copy-on-write, so every test starts from the exact same known-good state.

  • One click to save the current state as a reusable base image
  • Instant cloning — no re-installing before every run
  • Manage saved base images from Preferences whenever you want to clean up
Everything else you'd expect

Integrations that respect your actual toolchain.

Shared folders

Share host folders straight into a workspace — mounted automatically for macOS guests, with a copy-paste command for Linux.

SSH & VS Code, one click away

Quick SSH access to any workspace, plus a generated VS Code Remote-SSH config so your editor connects the moment the guest is up.

Serial console

A built-in terminal for debugging a Linux guest that never brings up a display — no external SSH client required.

Clipboard sharing

Copy and paste between your Mac and a Linux workspace like it's a window on your own desktop.

Rosetta 2 for Linux

Run x86_64 Linux binaries at near-native speed on Apple Silicon, inside the workspace that needs them.

Pause & hibernate

Pause a workspace mid-task and pick up exactly where you left off, without leaving it running in the background.

Guest operating systems
