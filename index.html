New in 1.2

From nothing to a Linux shell, faster.

Version 1.2 is about the first few minutes: getting an image, getting it installed, and signing in.

Cloud images

Ubuntu, Debian, Fedora and Rocky Linux boot from their official cloud images and set themselves up on first boot with your username, password, SSH keys and disk size. No installer, usually ready in about a minute.

Automatic installs

Prefer the full installer? Ubuntu Server and Desktop, Fedora and Rocky Linux boot straight into installing, answer every question with your Mac's language, keyboard and time zone, and restart into the finished system.

Image Library

Official images in one place, downloaded from each project's own servers and checked against its published checksum. Pause and resume, reuse an image for every new workspace, or import an ISO or QCOW2 file you already have.

Built-in SSH terminalPro

Open Terminal signs in with a key your Mac keeps in its keychain and checks the workspace's host key. Tabs, text size and color schemes. The ssh command stays free, for Terminal, VS Code or another computer.

AI Sandbox + AI Bridge
The two features that matter most

Built around local AI, and environments you can afford to throw away.

AI Bridge: local model inference, no cloud in the loopPro

Run inference on your Mac's own GPU and reach it from inside a workspace as a standard chat-completions endpoint, just like any local server. Build and test agents, tool calling and RAG pipelines against a model that never leaves the machine. No API keys, no usage costs, no data leaving your Mac.

  • Works with local model servers such as Ollama and MLX
  • Nothing is sent to Velo Workspaces or any third party
  • AI Sandbox profile is sized for agent frameworks and tooling out of the box

Disposable Workspaces: the way QA is supposed to workPro

Start a clean VM for exactly one test run, and it cleans up after itself when you close it. No snapshot to remember to delete, and no doubt about whether something left over from last time made a pass look real. Save a fully configured workspace (OS, packages, dotfiles, everything) as a base image once, then clone disposable workspaces from it in seconds with copy-on-write, so every test starts from the same known-good state.

  • One click to save the current state as a reusable base image
  • Instant cloning, with no reinstall before every run
  • Manage saved base images from Preferences whenever you want to clean up

Everything else you'd expect

Integrations that respect your actual toolchain.

Shared folders

Share folders from your Mac straight into a workspace: mounted automatically for macOS guests, with a copy-and-paste command for Linux.

SSH, VS Code and other computers

Copy an ssh command, open a generated VS Code Remote-SSH config, or reach a workspace from another computer on your network through your Mac with ssh -J.

Serial console

A console for debugging a Linux guest that never brings up a display or a network, with no SSH client needed.

Clipboard sharing

Copy and paste between your Mac and a Linux workspace like it's a window on your own desktop.

Rosetta 2 for LinuxPro

Run x86_64 Linux binaries at near-native speed on Apple Silicon, inside the workspace that needs them.

Pause & hibernate

Pause a workspace mid-task and pick up exactly where you left off, without leaving it running in the background.

Guest operating systems

Run the Linux you need.

Official cloud images for Ubuntu, Debian, Fedora and Rocky Linux. Installers for those, plus Kali Linux, NixOS and Alpine. macOS guests on Apple silicon. Every image comes straight from the project's own servers.
