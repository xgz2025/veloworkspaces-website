Para Mac con Apple Silicon

VM Linux reales en tu Mac, listas en un minuto.

Elige Ubuntu, Debian, Fedora o Rocky Linux, pon un usuario y una contraseña, y el espacio de trabajo se configura solo desde la imagen cloud oficial de la distribución. ¿Prefieres el instalador? Ubuntu, Fedora y Rocky Linux se instalan solos. Cuando termines, tira el espacio de trabajo o déjaselo a un agente de IA.

Disponible enApp Store Novedades de la 1.2

macOS 14 o posterior. Pensado para Apple Silicon; los invitados Linux también funcionan en Mac con Intel. Sin cuenta.

Novedades de la 1.2

Del Mac vacío a una shell de Linux, más rápido.

La versión 1.2 cuida los primeros minutos: conseguir una imagen, instalarla e iniciar sesión.

Imágenes cloud

Ubuntu, Debian, Fedora y Rocky Linux arrancan desde sus imágenes cloud oficiales y se configuran solos en el primer arranque con tu usuario, contraseña, claves SSH y tamaño de disco. Sin instalador, listos en un minuto aproximadamente.

Instalaciones automáticas

¿Prefieres el instalador completo? Ubuntu Server y Desktop, Fedora y Rocky Linux arrancan directamente en la instalación, responden a cada pregunta con el idioma, el teclado y la zona horaria de tu Mac y reinician en el sistema ya instalado.

Biblioteca de imágenes

Las imágenes oficiales en un solo lugar, descargadas de los servidores de cada proyecto y verificadas con su suma de comprobación publicada. Pausa y reanuda, reutiliza una imagen en cada espacio nuevo o importa un archivo ISO o QCOW2 que ya tengas.

Terminal SSH integradoPro

«Abrir Terminal» inicia sesión con una clave que tu Mac guarda en su llavero y comprueba la clave de host del espacio de trabajo. Pestañas, tamaño de texto y esquemas de colores. El comando ssh sigue siendo gratis, para Terminal, VS Code u otro ordenador.

Puente de IA — inferencia de modelo local, sin nube de por medioPro

Ejecuta inferencia en la propia GPU de tu Mac y accede a ella desde dentro de un espacio de trabajo como un endpoint estándar de chat-completions — igual que accederías a cualquier servidor local. Crea y prueba agentes, llamadas a herramientas y pipelines de RAG contra un modelo que nunca sale de la máquina. Sin claves de API, sin costes de uso, ningún dato sale de tu Mac.

  • Funciona con servidores de modelos locales como Ollama y MLX
  • Nada se envía a Velo Workspaces ni a terceros
  • El perfil Sandbox de IA viene dimensionado de fábrica para frameworks de agentes y herramientas

Espacios de trabajo desechables — como debería ser el QAPro

Levanta una VM limpia para exactamente una ejecución de pruebas, y deja que se limpie solo en cuanto lo cierres — sin snapshots que recordar borrar, sin esa duda de “espera, ¿dejé algo instalado de la última vez?” que hace dudar de si una prueba superada es real. Sella un espacio de trabajo completamente configurado — SO, paquetes, dotfiles, todo — en una imagen base una sola vez, y luego clona nuevos espacios de trabajo desechables a partir de ella en segundos usando copy-on-write, para que cada prueba empiece exactamente desde el mismo estado conocido y funcional.

  • Un clic para guardar el estado actual como imagen base reutilizable
  • Clonado instantáneo — sin reinstalar antes de cada ejecución
  • Gestiona las imágenes base guardadas desde Preferencias cuando quieras hacer limpieza

Integraciones que respetan tu toolchain real.

Carpetas compartidas

Comparte carpetas del host directamente en un espacio de trabajo — montadas automáticamente en invitados macOS, con un comando para copiar y pegar en Linux.

SSH, VS Code y otros ordenadores

Copia un comando ssh, abre una configuración de VS Code Remote-SSH generada o llega a un espacio de trabajo desde otro ordenador de tu red a través de tu Mac con ssh -J.

Consola serie

Una consola integrada para depurar un invitado Linux que nunca levanta una pantalla — sin necesidad de un cliente SSH externo.

Portapapeles compartido

Copia y pega entre tu Mac y un espacio de trabajo Linux como si fuera una ventana de tu propio escritorio.

Rosetta 2 para LinuxPro

Pausa & hibernación

Pausa un espacio de trabajo a mitad de una tarea y retómalo exactamente donde lo dejaste, sin dejarlo ejecutándose en segundo plano.
