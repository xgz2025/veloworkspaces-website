Roadmap

What's shipped, and what's coming next.

Taken from the app's own release notes. If something here matters to you, or you'd like to see something that isn't, email us. The address is at the bottom of the page.

Shipped

v1.2.0 Shipped

The quickest way yet to a working Linux VM. Choose Cloud image when you create a workspace and Velo Workspaces downloads the official Ubuntu, Debian, Fedora or Rocky Linux cloud image, sets up your account and SSH key with cloud-init, and has the system ready to sign in to in about a minute.

Prefer a full installer? Ubuntu, Fedora and Rocky Linux installs can now run on their own. And a built-in SSH terminal signs in to a workspace with a key kept in your Keychain. Everything in this release is free except the terminal, which is part of Pro. The 1.2 release post walks through it all.

  • Cloud images for Ubuntu 26.04 and 24.04 LTS, Debian 13 and 12, Fedora 44, and Rocky Linux 10 and 9
  • Automatic installs for Ubuntu Server and Desktop, Fedora Server and Everything, and Rocky Linux
  • An Image Library in Settings › Images: downloads are checked against the vendor's checksum and reused, and base images live there too
  • Built-in SSH terminal (Pro). The Access tab shows a copyable ssh command, a VS Code Remote block and an ssh -J command for other computers, all free
  • More installers: Fedora Workstation, Kali Linux, NixOS 26.05 and 25.05, and Alpine Linux 3.24
  • Fixed: arm64 Fedora, Rocky Linux and NixOS installer ISOs that only a CD drive could boot now start on Apple silicon
  • The macOS restore image stays in the library, so a second macOS workspace doesn't download it again

v1.1.0 Shipped

September 2026

Velo Workspaces became free to download. Anyone who had already bought it keeps everything they paid for, permanently and at no extra cost, with nothing to restore or sign up for. Everyone can create and run as many Linux and macOS workspaces as they like for free, with the console, shared folders, SSH details, the VS Code Remote helper and diagnostics export included.

Velo Workspaces Pro adds AI Bridge, restore points, disposable workspaces, base images and Rosetta for $3.99 a month, $24.99 a year, or $79.99 once, with a free week to try it. Pro unlocks creating these things; it never takes away what you already have. If a subscription ends, your workspaces still start, restore points still restore and base images still work. The pricing section has the full list.

  • Diagnostics opens in its own window, like Preferences
  • Support and Feedback moved into the sidebar, and the Help menu opens the support page in your language
  • Fixed shared folders sometimes coming back in a different order after a relaunch
  • Fixed CPU usage not updating in the Overview and Resources tabs

v1.0.1 Shipped

AI Bridge provider fixes and a crash fix. Before this release, every workspace sent its AI Bridge traffic to Ollama's default port (11434) whichever provider you had selected, so if you ran MLX or llama-server on 8080, requests arrived at a port with nothing listening. The bridge now forwards to the port your provider actually uses, and switching providers takes effect right away, without a restart.

The crash: an AI Bridge connection that closed while data was still in flight (a cancelled generation, a client timing out, a benchmark saturating the channel) could take down the whole app and every running workspace with it. It was rare in everyday use, since a thousand streamed completions in a row never triggered it, but cancelling a transfer reproduced it reliably.

  • You can pick the host provider for a disposable workspace when you create it, the only moment it can be set
  • CPU, memory and storage values typed in Advanced Settings are kept even if the cursor is still in the field
  • Lower latency between AI Bridge and the inference server
  • Clearer diagnostics: logs show both the channel port a workspace dials and the host port its traffic goes to

Next up

Planned for the 1.2.x updates. There are no committed dates; this section changes when the plan does.

Kali Linux and Alpine Linux cloud images Next

Kali publishes its arm64 cloud image as a compressed archive rather than a disk image, so the app needs to unpack it first. Alpine's UEFI cloud-init image follows. Both will then set themselves up on first boot, just like Ubuntu or Debian today.

Catalog updates without an app update Next

New distribution releases and changed download locations can reach the app from an updated catalog, so a new Ubuntu or Fedora version doesn't have to wait for an App Store review.

Planned

Not started yet. The order is roughly the order we expect to get to them, not a promise.

Automatic Debian and Kali installs Planned

Debian's installer only reads an answer file (preseed) from a boot argument or from inside its own initrd, so it needs a different approach from Ubuntu and Fedora. Until then, the Debian cloud image is the hands-free way to get Debian.

SSH without the Local Network prompt Planned

Connecting the terminal over virtio-vsock, the same private channel AI Bridge uses, instead of the virtual network. macOS would then have no reason to ask for Local Network access.

Scriptable workspace creation Planned

A URL scheme (veloworkspaces://create?...) you can call from any shell with open, to create or start workspaces from a script or a CI step without installing anything extra.

Shortcuts and App Intents Planned

Native Shortcuts actions for common workspace tasks, so they fit into your own automations without opening a terminal.
