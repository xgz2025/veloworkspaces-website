Does Velo Workspaces Run Windows on Apple Silicon?

Short answer: no. Here's why, what Velo Workspaces runs instead, and where to go if a Windows VM is what you need.

By Gaoliang Luo · Published September 23, 2026 · Updated September 28, 2026

No

Velo Workspaces doesn't run Windows guests, on Apple silicon or on Intel Macs. The reason is technical rather than a policy choice. Velo Workspaces is built on Apple's Virtualization framework, and the Windows installer can't run on the virtual machine platform that framework provides. Getting past that means building a different kind of virtualization engine altogether, not flipping a setting, so the 1.2.x updates on the roadmap don't change it.

What Velo Workspaces does run

  • Apple silicon Macs: Linux and macOS guests, hardware-virtualized with the Virtualization framework.
  • Intel Macs: Linux guests.

Linux is where it shines. Since 1.2, Ubuntu, Debian, Fedora and Rocky Linux come as official cloud images that are ready to sign in to about a minute after they download, and Ubuntu, Fedora Server and Rocky Linux can install themselves from their own ISOs. For disposable VMs for AI agent sandboxing, QA, clean-room bug reproduction or keeping a project's dependencies off your Mac, start with the fundamentals and the complete setup guide.

If you need Windows

Two good options, both of which handle Windows on Apple silicon properly:

  • Parallels Desktop is the one to reach for. It has serious engineering behind Windows on Arm: one-step Windows 11 installation, DirectX 11 and OpenGL support for compatible games, and Coherence mode for running Windows apps alongside Mac ones.
  • UTM is free and open source and can run Windows on Apple silicon too, with more manual setup and without Parallels' polish or graphics acceleration.

Velo Workspaces vs. Parallels Desktop vs. UTM covers pricing and the rest of what each does, including this gap.

Moving the other way, bringing a Linux VM you already have in UTM, VMware Fusion or Parallels into Velo Workspaces? See the migration guide.
