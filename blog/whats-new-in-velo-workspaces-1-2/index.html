What's New in Velo Workspaces 1.2

The biggest update since launch is about one thing: getting from "I need a Linux machine" to a shell prompt as fast as possible. Official cloud images, installers that run themselves, and a terminal that signs you straight in.

By Gaoliang Luo · Published September 28, 2026

Linux in about a minute, from official cloud images

Until now, a new Linux workspace meant downloading an installer ISO and clicking through the distribution's installer. That still works, but it's no longer the quickest way. When you create a workspace, the first choice is now Cloud image: the prebuilt disk images distributions publish for cloud servers, with cloud-init built in.

Pick a distribution and version, type a username and password, and click Create Workspace. Velo Workspaces downloads the image from the vendor's own servers, checks it against the vendor's published checksum, converts it for Apple's Virtualization framework, and hands cloud-init your account, this Mac's SSH key, your time zone and a hostname on a small seed disk. The first boot sets everything up and grows the disk to the size you chose. It's usually ready to sign in to about a minute after the download finishes.

Available in 1.2:

  • Ubuntu 26.04 LTS and 24.04 LTS
  • Debian 13 and 12
  • Fedora 44 Cloud Base
  • Rocky Linux 10 and 9

There's no default user with a known password; the only account is the one you named. Each cloud workspace also gets its own SSH host key, generated in advance, so the first connection is trusted without a fingerprint prompt.

Installers that run themselves

If you'd rather run a distribution's own installer, for Ubuntu Desktop for example, choose Installer image. For Ubuntu, Fedora and Rocky Linux, leave Automatic installation on and the app answers the installer's questions for you: your account and SSH key, plus this Mac's language, keyboard and time zone.

  • Ubuntu Server and Desktop use Ubuntu's autoinstall. Ubuntu always asks once before erasing the disk, so click Confirm Installation in the banner.
  • Fedora Server and Everything, and Rocky Linux Minimal and DVD, use a kickstart file that Anaconda picks up by itself. No questions at all.

When the install finishes, the workspace restarts into the new system. Debian's installer, Fedora Workstation, Kali Linux, NixOS 26.05 and 25.05, and Alpine Linux 3.24 are in the catalog too, installed by hand in the workspace's display. For a hands-free Debian, use the cloud image.

Some of these ISOs, Fedora's, Rocky Linux's and NixOS's aarch64 images among them, are built to boot from a CD, and Apple's framework has no CD drive. Velo Workspaces now gives its own copy of such an ISO a partition table the firmware can boot from, so they start normally on Apple silicon.

The Image Library

Everything you download or import is kept in one place: Settings › Images, also reachable from Images in the sidebar. Cloud images, installer ISOs and the macOS restore image are under Installers & Cloud Images, and saved base images under Base Images. Images are reused, so your second Ubuntu workspace doesn't download anything, and a second macOS workspace doesn't fetch another 15 GB restore image.

Already have a file? Choose File… on the Image step, or Import… in Settings › Images. If its name appears in the vendor's checksum list, the app verifies it against the official checksum. And Boot from an existing virtual disk now accepts QCOW2 disks as well as raw ones, which makes moving a VM from UTM a matter of choosing its disk file.

A built-in SSH terminal

Each workspace's Access tab (formerly Developer Tools) now has an SSH section that shows when the workspace's SSH server is ready, and an Open Terminal button. The terminal signs in over SSH with a key Velo Workspaces creates for this Mac and keeps in your Keychain; workspaces made from cloud images and automatic installs already trust it. For a system you installed by hand, type its username, sign in once with the password, and click Install Key. Manage the key, or import your own, in Settings › Access.

The terminal is part of Pro. Everything else in the Access tab stays free: the workspace's address, a copyable ssh command for Terminal or any client (using your own SSH key, which you can add when creating the workspace), the VS Code Remote configuration, and an ssh -J command that lets other computers on your network reach the workspace through your Mac.

macOS treats the Mac's private virtual network as part of the local network, so the first time the app checks a workspace's SSH server, macOS asks for Local Network access. Velo Workspaces only connects to its own workspaces. If you decline, the Access tab says so and links to the setting.

What's free and what's Pro

Cloud images, automatic installs and the Image Library are free, like unlimited Linux and macOS workspaces, the console, shared folders, SSH details and the VS Code helper. Velo Workspaces Pro adds the built-in SSH terminal to AI Bridge, restore points, disposable workspaces, base images and Rosetta, for $3.99 a month, $24.99 a year, or $79.99 once, with a free week to try it. Anyone who bought Velo Workspaces 1.0 keeps every Pro feature at no cost.

Try it

  1. Update Velo Workspaces from the App Store (macOS 14 or later).
  2. Choose a library in the sidebar, such as Developer Workspace, and click +.
  3. Choose Cloud image, then Ubuntu 26.04 LTS, and click Continue.
  4. Pick a profile, enter a username and password, and click Create Workspace.
  5. When it's ready, open the Access tab and click Open Terminal, or sign in at the console.

Linux guests run on Apple silicon and Intel Macs; macOS guests need Apple silicon. Velo Workspaces doesn't run Windows guests (here's why).

What's next

Kali Linux and Alpine Linux cloud images, and catalog updates that don't need an app update, are next on the roadmap. Questions or requests: support@veloworkspaces.com, and the support page covers the new features in detail.

Where to go from here: Ubuntu, Debian, Fedora and Rocky Linux on Apple Silicon, which distribution fits your work, and running AI agents in a workspace. Or download Velo Workspaces and try it yourself.
