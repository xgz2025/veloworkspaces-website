適用於 Apple 晶片 Mac

用後即焚、可重現的環境——不是玩具級 VM 應用程式。

Velo Workspaces 在你的 Mac 上執行真正隔離的 Linux 與 macOS 環境，圍繞 AI 研究人員、QA 工程師、DevOps 專業人員與軟體工程師的實際工作方式打造——而不是「再跑一個作業系統」式的獵奇玩具。

Apple 晶片 Mac，macOS 14 或更新版本。無需帳號，不依賴雲端。

適合對象

四種工作，四種為其打造的預設。

每個工作區都從一個為具體任務量身打造的預設開始，而不是靠猜——CPU、記憶體與儲存空間依任務所需設定，也可以自行設定。

AI 沙盒 + AI 橋接
最重要的兩項功能

圍繞本機 AI，以及你可以放心捨棄的環境而打造。

AI 橋接——本機模型推論，全程無需雲端

在 Mac 自身的 GPU 上執行推論，並以標準 chat-completions 介面從工作區內部存取它——就像連接任何本機伺服器一樣。建構與測試代理、工具呼叫與 RAG 流程，對接一個始終不離開這台機器的模型。無需 API 金鑰，無使用費用，資料不離開你的 Mac。

  • 可搭配 Ollama 等本機模型伺服器使用
  • 不會傳送任何內容給 Velo Workspaces 或任何第三方
  • AI 沙盒預設預設即已為代理架構與相關工具準備好合適的資源

於 Mac mini（Apple M1）測得

首個 token 產生時間 280 毫秒 原生 310 毫秒 經由 AI 橋接 +10%
輸送量 12.75 tok/s 原生 12.27 tok/s 經由 AI 橋接 −4%

使用 Llama 3，於主機上直接測試（回送）與透過 AI 橋接從 Linux 工作區存取兩種方式各執行 5 次取平均。結果會因模型、Mac 機型與負載而異。

用後即焚工作區——QA 本該如此

為單次測試啟動一個乾淨環境，關閉的瞬間就自動清理乾淨——不必記得刪除快照，也不必懷疑「上次是不是裝了什麼沒清乾淨」，進而懷疑測試結果是否可信。將設定完整的工作區——作業系統、套件、點檔案（dotfiles），全部——一次封存為基礎映像檔，之後透過寫入時複製（copy-on-write）在幾秒內從中複製出新的用後即焚工作區，讓每次測試都從完全相同、已驗證可用的狀態開始。

  • 一鍵將目前狀態儲存為可重複使用的基礎映像檔
  • 即時複製——無需在每次執行前重新安裝
  • 隨時在偏好設定中管理已儲存的基礎映像檔，需要時清理
其他你所期待的一切

尊重你真實工具鏈的整合功能。

共用資料夾

將主機資料夾直接共用進工作區——macOS 虛擬機器自動掛載，Linux 則提供可複製貼上的掛載指令。

SSH 與 VS Code，一鍵直達

快速 SSH 存取任意工作區，並自動產生 VS Code Remote-SSH 設定，虛擬機器一啟動編輯器即可連線。

序列主控台

內建終端機，用於偵錯從不啟動圖形介面的 Linux 虛擬機器——無需外部 SSH 用戶端。

剪貼簿共用

在 Mac 與 Linux 工作區之間複製貼上，就像操作自己桌面上的一個視窗。

適用於 Linux 的 Rosetta 2

在需要的工作區內，讓 x86_64 Linux 程式在 Apple 晶片上以近乎原生的速度執行。

暫停與休眠

在作業進行中暫停工作區，之後從原處繼續，無需讓它在背景持續執行。
